# BhashaSetu AI

> India's Multilingual AI Platform for Entrepreneurs

BhashaSetu AI helps rural entrepreneurs, farmers, MSMEs, students, women entrepreneurs, and small businesses grow using AI-powered mentorship in 13 Indian languages.

## Languages

Hindi · English · Marathi · Gujarati · Tamil · Telugu · Kannada · Malayalam · Punjabi · Bengali · Urdu · Odia · Assamese

## Stack

| Layer    | Technology                                  |
|----------|---------------------------------------------|
| Frontend | Next.js 15, React 19, TypeScript, TailwindCSS |
| Backend  | FastAPI, Python 3.11                        |
| ORM      | Prisma (prisma-client-py)                   |
| Database | PostgreSQL 16                               |
| Cache    | Redis 7                                     |
| AI       | Google Gemini 2.0 Flash                     |
| Auth     | JWT + Refresh Tokens                        |
| Deploy   | Railway (API) + Vercel (Frontend)           |
